# Office Shift Manager — Frontend

React 19 + Vite frontend for the Office Shift Manager application.

See the [root README](../README.md) for full setup, build, and running instructions.

## Quick start

```bash
npm install
npm run dev      # start dev server on http://localhost:5173
```

## Scripts

| Script | Description |
|--------|-------------|
| `npm run dev` | Start the Vite dev server (http://localhost:5173) |
| `npm run build` | Build the production bundle to `dist/` |
| `npm run preview` | Preview the production build locally |
| `npm run lint` | Run the Oxlint linter |
